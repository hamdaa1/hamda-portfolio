Brycen Japan · 2 Months · Lead Design Engineer

Warehouse Digital Twin Simulator for Logistics

I led a UI/UX redesign of Brycen's Warehouse Digital Twin Simulator (WDTS), addressing a core usability problem: a direct Japanese-to-English translation had left the interface visually flat and cognitively demanding to parse. Using Figma, I introduced color-coded zones, an icon system, corrected typography, and natural English copy — grounding every decision in hands-on inspection of the existing front-end. The redesign was presented to and approved by the CEO for immediate implementation.

ROLE & TIMELINE

Lead Design Engineer — Brycen Japan (2 Months)

CORE METHODS

Figma, DevTools, JS Console, JSON Analysis

OUTCOME

Approved by CEO for immediate production rollout

The Problem: High Cognitive Load

The core challenge was one of cognitive load: WDTS was functionally complete, but its interface gave every element equal visual weight, so users had to actively read and parse the screen rather than glance at it and understand it instantly. This showed up concretely in several ways:

  • Flattened Type Hierarchy: A single monospace font and uniform ALL CAPS styling flattened the overall hierarchy.
  • Undifferentiated Zones: Zones and object types were undifferentiated text with no color or iconography.
  • Bare Status Labels: System status appeared as bare text labels rather than a recognizable visual signal.
  • Fragmented UI Copy: UI copy (e.g., "SELECT AN OBJECT," "NO PREVIEW") read as terse system fragments rather than natural English instructions.

Research & Discovery Insights

Hands-on use revealed that the core issue was legibility, not missing features.

The Japanese-to-English Typography Root Cause

The typography problem traced to a specific root cause: the interface was translated directly from Japanese, and Japanese script has no case distinction at all — no equivalent of uppercase or lowercase. The original's blanket ALL CAPS styling was likely a convention carried over unquestioned since there was no case signal to preserve in the source language. In English, case is a real hierarchy tool: sentence case reads as normal text, ALL CAPS reads as emphasis. Applying it uniformly meant English users lost that hierarchy entirely.

Technical Inspection & Engineering Grounding

  • DevTools Front-End Inspection: Inspected front-end components (toolbar, panels, playback controls) via browser dev tools to see which elements were reused.
  • Simulation JSON Analysis: Analysed exported simulation JSON across runs to evaluate how interface actions translated into output, informing improvements to the export workflow.
  • JS Console State Verification: Wrote lightweight JavaScript console scripts during exploratory testing to observe actual state transitions firsthand.
